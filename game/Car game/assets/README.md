# Apex Nitro — 3D Open-World Car Game

## Project Files
- `index.html` — Main entry point
- `style.css` — Sideways landscape layout, neon showroom UI & animations
- `vehicles.js` — 31 realistic Cars, Trucks, and Bikes with curated metallic colors
- `audio.js` — Web Audio API engine RPM, nitro, crash & coin SFX
- `city3d.js` — Sculpted 3D vehicle models & architectural building facades (Three.js)
- `script.js` — Game controller with `localStorage` auto-save
- `assets/` — Logo, loading backgrounds, and vehicle showroom artwork

## Deploy on GitHub Pages
1. Create a new repository on GitHub (e.g., `apex-nitro-3d`).
2. Upload all files and the `assets/` folder from this ZIP into the repository root.
3. Open **Settings → Pages**, select the `main` branch (`/root`), and click **Save**.
4. Open the generated GitHub Pages URL on your phone or PC to play!
