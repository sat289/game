# ST GAMES — 3D Highway Car & Bike Racer (v3.0)

## Included Files
- `index.html`: 16:9 full-screen lobby and gameplay stage (no external background PNG dependencies).
- `style.css`: Responsive 16:9 landscape lock, tactical lobby zones, and highway HUD styling.
- `game.js`: Endless 4-lane PBR textured asphalt highway with backside chase camera, dynamic FOV speed scaling, and live `.glb`/`.gltf`/`.obj` 3D car loader.
- `main.js`: 3D showroom turntable, direct 3D car file uploader, Firebase (`friendsgame-872f5`) + `localStorage` account sync, store, upgrades, and library.
- `vehicles.js`: Fleet of 12 real 3D cars and 3D bikes (`AGERA_3D_DATA` and `MOTO_3D_DATA`).
- `maps.js`: 8 highway environments (`Sunset Highway`, `Countryside Autobahn`, `Desert Route 66`, `Alpine Snow Pass`, `Volcano Coastway`, `Night City Metro`, `Ocean Breeze Drive`, `Cyber Spaceway`).
- `agera_3d_data.js`: Prebaked 3D mesh geometry for instant offline/mobile loading.
- `admin.html`: Standalone GitHub + Firebase admin studio.
