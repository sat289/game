# ST Foods Delivery - Kakinada Real 3D Map Car Game (Pushpa 2 Edition)

## Files Included in This ZIP Package
1. **`index.html`** — Main 16:9 Full-Screen 3D Car & Flying Delivery Game with Real Kakinada OpenStreetMap Roads (3,252 roads), Real Extruded Buildings (604 footprints), 3D Building Signboards, Green Highway Navigation Boards, ST Foods Smartphone App, and the Pushpa 2 Shipping Container Delivery Cutscene.
2. **`map.html`** — Standalone Offline Kakinada 2D/3D Vector City Map Explorer & Route Planner (`📍 KAKINADA`) with all 3,252 roads and 604 buildings pre-saved inside so it works 100% offline without Overpass timeouts.
3. **`kakinada_map_data.js`** — Pre-compiled Kakinada OpenStreetMap coordinate dataset generated from your `export (1).geojson`.
4. **`kakinada_real_osm.geojson`** — Your complete Kakinada OpenStreetMap GeoJSON file (`3,856` features).

## How to Play Offline (Mobile or PC)
1. Extract this `.zip` file to any folder on your phone or computer.
2. Open **`index.html`** in Chrome or any browser (or upload the folder to your GitHub Pages repository `sat289/game`).
3. Tap **ENTER 16:9 FULL SCREEN MODE**.
4. Use the **ST Foods Smartphone** on the left to pick any real Kakinada hotel (*Domino's & Ibaco Bhanugudi*, *Chitti Babu Kodi Pulao*, *Udipi Hotel*, *Vinayaka Tiffins*, *GRT Grand*, *Aditya Canteen*, *Hotel City Inn*), collect the food parcel, and deliver it to **Pushpa Raj** inside the red **Pushpa 2 Shipping Container**!
