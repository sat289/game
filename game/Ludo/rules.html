html Ludo Rules Basic Ludo Rules (summary)
  • Each player has 4 tokens. Objective: move all tokens from base to home. [citation:4)
  • A token can only enter the track from base when you roll a 6. [citation:4]On rolling a 6 you get an extra turn. (citation:4]
  • If your token lands on on a square occupied by an an opponent, you capture it and send it back to base, unless the square is a safe square. [citation:4]
  • Safe squares are typically the colored start squares and a few marked spaces adjust per variant. (citation:2]
  • T move a token into home you usually must roll the exact number required. [citation:4]
