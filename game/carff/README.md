# ST GAMES — 3D Highway Racer (v6.0 • Cars-Only Edition)

## Features Included in v6.0
1. **Mobile Tilt / Gyroscope Steering (Default) + Desktop Keyboard**: Rotate mobile left/right to steer smoothly (enabled by default). Desktop keyboard (`A`/`D`, Arrow keys) & on-screen buttons are usable and configurable inside **Settings (`⚙️`)** along with Tilt Sensitivity.
2. **Cars Only**: All bikes removed from Store, Garage, Traffic, Events, and Admin.
3. **Clean Free Fire India-Style Lobby**: Single sleek top bar (Profile + UID + T-Coins + Diamonds + Utility Icons), uncluttered left menu column, right vertical Friends/Squad strip, center 3D ramp, bottom-left chat ticker & dock, and bottom-right Map selector + golden `START` button.
4. **Realistic Narrower Road + Smooth Car Physics + Uploaded Cars as Opponents**: Narrowed the 4-lane highway to realistic proportions (`10.8` units) with smooth damped steering. Any 3D car uploaded in `admin.html` automatically runs on the highway as opponent traffic!
5. **First-Click Fullscreen**: Automatically enters 16:9 landscape fullscreen on the very first tap/click.
6. **Friends System (Team Code & UID) + Duo Lobby**: Auto-generated numeric UID for Guest and Google/Firebase sign-ins (`friendsgame-872f5`). Add friends via UID or join via 6-digit Team Code; when a friend joins your lobby, **two 3D cars** appear side-by-side on the ramp and rotate smoothly!
7. **T-Coins Near-Miss System**: Passing closely alongside highway cars awards **T-Coins** (`+25`/`+50` × combo) live on screen and saves them to your balance.
8. **Voice & Message System Below Vehicle**: Dedicated **Voice Mic (`🎙️`)**, **Audio (`🔊`)**, and **Message (`💬`)** buttons positioned directly below your 3D car, synced with Firebase chat.
